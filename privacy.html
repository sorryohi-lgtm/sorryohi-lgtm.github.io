Privacy Policy

Last updated: November 28, 2026

Shortform Studio is a personal tool used only by its owner to publish videos to the owner's own YouTube channels, Facebook Page and Instagram account.

What it accesses

With the owner's permission, through Google sign-in (OAuth), it uses these YouTube permissions:

  • Upload videos (youtube.upload): to post the owner's videos.
  • Read channel data (youtube.readonly): to read public video statistics and search public videos.
  • Read analytics (yt-analytics.readonly): to read the owner's channel analytics.

How data is stored

Sign-in tokens and statistics are stored only on the owner's own computer. Nothing is sold, shared with third parties or used for advertising. Shortform Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the tool's data folder removes everything it stored.

Facebook and Instagram

With the owner's permission, through Facebook Login, the tool uses these permissions only on the owner's own Facebook Page and Instagram professional account:

  • pages_show_list, business_management, instagram_basic: to find the owner's Page and Instagram account.
  • pages_manage_posts, instagram_content_publish: to post the owner's videos.
  • pages_read_engagement, read_insights, instagram_manage_insights: to read statistics of the owner's own posts.
  • pages_manage_engagement, pages_read_user_content: granted because Meta ties them to Page statistics. The tool does not read, store or manage other people's comments or posts.

Tokens and statistics are stored only on the owner's own computer. Nothing is sold, shared or used for advertising. Access can be removed in Facebook Settings under Business integrations, and deleting the tool's data folder removes everything it stored.
