Privacy Policy

Last updated: November 22, 2026

Shortform Studio is a personal tool used only by its owner to publish videos to the owner's own YouTube channels.

What it accesses

With the owner's permission, through Google sign-in (OAuth), it uses these YouTube permissions:

  • Upload videos (youtube.upload): to post the owner's videos.
  • Read channel data (youtube.readonly): to read public video statistics and search public videos.
  • Read analytics (yt-analytics.readonly): to read the owner's channel analytics.

How data is stored

Sign-in tokens and statistics are stored only on the owner's own computer. Nothing is sold, shared with third parties or used for advertising. Shortform Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the tool's data folder removes everything it stored.
